## 1. 需求来源

用户提出两件事（条目编号沿用设计文档 §1）：

- **① 配对提示措辞**：Cherry Studio 桌面端的配对界面**只显示二维码**，配对信息（地址/端口/
  一次性邀请）要点开扫码后的网页才看得到；现有文案「复制生成的配对信息」与实际操作不符。
- **② 工具启用范围**：14 个 `cherry_*` 工具当前在**所有**工作区全局注册；需要可配置为
  「全局」或「仅在勾选的工作区里启用」，未启用的工作区里这些工具**不出现在模型的工具表里**。

## 3. 由澄清推定的硬约束（**不是**新澄清，是对 C1–C5 的必然要求）

- C1 的"省上下文"⇒ 必须是**真隐藏**（不进工具表），不是"可见但调用报错"，也不是渲染层过滤
  （设计文档 §3 反目标"假限制"）。
- C2 的"没有逃生口" + "改配置后立刻生效"⇒ 保存后对**所有 live agent** 重算，**不需要**重启 DSH、
  **不需要**新建会话（D2/D10/B4）。
- C2/C5 ⇒ 设置页与 `/cherry-remote/api` **不受**范围约束（否则被排除的工作区无法自救与配对，D9）。
- C3 ⇒ 读不出来的作用域文档必须落到**更严**的一侧（不得静默变成"全局"，§3 反目标"静默损坏"）。
